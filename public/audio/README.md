# Ambient audio files

- `liecio-light-rain-109591.mp3` is the single looped rain ambience track.
- `thunder-sound.mp3` is the primary sound played occasionally when Distant Thunder is enabled.
- `distant-thunder.wav` is the fallback used when the primary thunder sound cannot play.

The interface remains functional and reports unavailable rain ambience when the rain file is missing. Thunder falls back to the WAV file when the primary MP3 cannot play.
